# SMIS — School Management Information System

A school management system for a single Philippine junior and senior high school (Grades 7–12, DepEd),
configurable to run as a **public** school (no tuition) or a **private** school (tuition, cashiering,
ESC / SHS Voucher billing). Includes the school's public website.

Status: **pre-planning**. Development environment and skills are set up; no application code yet.

- Decisions and open questions: [`docs/00-open-questions.md`](docs/00-open-questions.md)
- Development environment and skills: [`docs/01-development-environment.md`](docs/01-development-environment.md)
- Master specification: `docs/research/reports/DepEd JHS SHS school system spec.md` (in progress)

reference only; it was superseded when the scope changed to JHS–SHS.
